# Phase 2 · PyTorch and TorchGeo

Skip generic PyTorch-from-zero tutorials go straight to TorchGeo's own
docs, which teach PyTorch conventions through geospatial examples.

  pretrained model on it

Goal for this phase: the plumbing (CRS-aware sampling windows, arbitrary band
counts), not model novelty yet. That comes in Phase 3.
