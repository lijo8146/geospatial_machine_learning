# Change detection

[6.1 What changed—and what only looks like change?](01_satellite_change_detection.ipynb)

A 75–90 minute lesson using synthetic red/NIR rasters, an NDVI threshold baseline, cloud masking, a grid-offset counterexample and a seasonal confound. No downloads, accounts or additional packages are required beyond the course environment. Includes an independent challenge and a 10-point rubric. Actual satellite imagery is a separate guided extension.
